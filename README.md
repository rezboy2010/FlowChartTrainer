# Чтение блок-схем

Автор учебного проекта: **Резяпкин Александр**. Целевая система для локального запуска — Windows 11.

Тренажёр второго типа задач: подбор целых входных чисел для заданной ветви или результата. Три готовые схемы, 1–2 условия в каждой, несколько арифметических действий. Включены теория с тремя примерами, тест из пяти вопросов и практика.

## Быстрый запуск на Windows 11

1. Установить [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0). На обычном компьютере с процессором Intel/AMD выбрать Windows x64, раздел **SDK**. На ARM-компьютере выбрать Arm64.
2. Распаковать весь архив в папку, например `C:\Projects\FlowchartTrainer`. Не запускать файлы внутри ZIP.
3. Дважды нажать `start.bat`. При первом запуске нужен интернет для восстановления пакетов NuGet.
4. Дождаться сообщения `Now listening on` и открыть **http://localhost:5080** в браузере.
5. Оставить окно запуска открытым. Для остановки нажать Ctrl+C.

HTML-файл двойным щелчком не запускается: Blazor загружает ресурсы по HTTP. Локальный сервер отдаёт файлы; учебные расчёты выполняются на C# в браузере. Отдельной серверной прикладной логики нет.

Ручной запуск из PowerShell в корне распакованного проекта:

```powershell
dotnet --list-sdks
dotnet run --project src/FlowchartTrainer.Web/FlowchartTrainer.Web.csproj --no-launch-profile --urls http://localhost:5080
```

VS Code с расширением C# Dev Kit удобен для изучения и изменения кода, но не обязателен для запуска.

## Как пользоваться

- **Главная:** краткая инструкция, автор, источники и переходы к разделам.
- **Теория:** обозначения фигур, присваивание, сравнение, подбор входа; три пошаговых примера, один с разбором ошибки.
- **Тест:** выбрать один вариант, проверить, прочитать пояснение, перейти дальше. Повторная проверка одного вопроса не увеличивает балл.
- **Практика:** выбрать схему и ввести начальное x и нажать «Разобрать число». Разбор сразу открывается на первом вычислении. На арифметическом шаге ввести новое y, в условии выбрать «Да»/«Нет». Кнопка проверки находится рядом с ответом. После верного ответа нажать «Дальше». В конце сравнить результат с целью.
- После завершения доступен список всех подходящих чисел. Его вычисляет тот же исполнитель схемы.

Ввод допустимого, но не подходящего для цели числа — нормальная попытка решения. Это отличается от ошибки формата или выхода за диапазон.

## Состояние и ограничения

- Состояние практики и теста хранится в памяти открытого приложения. Переход между разделами его сохраняет; перезагрузка сбрасывает.
- Изменение x, смена схемы и новая попытка сбрасывают предыдущую трассу, ответы и показ решений. Кнопка сброса сохраняет текст x для повторного запуска.
- Редактора схем, циклов, регистрации, базы данных и автоматического проигрывания нет.
- x и y — целые числа без физических единиц. Арифметика `long` с `checked`, только сложение, вычитание и умножение. Дробный ввод не поддерживается.
- На узком экране панели располагаются вертикально; сама схема прокручивается по горизонтали, сохраняя читаемый размер подписей.
- Разделы переключаются внутри одной страницы: отдельного URL для каждого раздела нет.
- Windows-скрипты подготовлены для Windows 11. Их нативный запуск на компьютере пользователя нужно проверить отдельно; сборка и автоматические проверки выполнялись в Linux.

## Проверки

Дважды нажать `check.bat` или выполнить:

```powershell
dotnet run --project tests/FlowchartTrainer.Tests/FlowchartTrainer.Tests.csproj -- test-results.json
```

Это исполняемые проверки на C# без стороннего тестового фреймворка. При успехе код возврата 0, при ошибке 1. Отчёт: [docs/TEST_RESULTS.md](docs/TEST_RESULTS.md). Сценарий самостоятельного прохождения учеником: [docs/CLASSMATE_TEST.md](docs/CLASSMATE_TEST.md).

## Публикация через GitHub Pages

Настройка сборки уже включена: `.github/workflows/pages.yml`. В репозитории открыть **Settings → Pages** и выбрать **Source → GitHub Actions**. После загрузки файлов в ветку `main` запустится **Deploy Blazor to GitHub Pages**: установка SDK .NET 10, автоматические проверки, сборка C# и публикация.

Ожидаемый адрес для репозитория `rezboy2010/FlowChartTrainer`: https://rezboy2010.github.io/FlowChartTrainer/ . Ссылка начнёт работать после успешного завершения Actions; публикация на GitHub пока не проверена из этой среды.

Путь приложения определяется автоматически из настроек Pages, поэтому локальный запуск через `start.bat` сохраняется. Посетителям не нужен установленный .NET. Инструкция с точными действиями — [PUBLISH_INSTRUCTIONS.txt](PUBLISH_INSTRUCTIONS.txt). Устройство публикации и ограничения — [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

Для оценки 7 необходимо проверить опубликованную версию без регистрации, в другом браузере или на другом устройстве и другим учеником. Заполнять результаты только после реальной проверки.
